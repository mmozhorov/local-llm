# Фаза 3 — Technical analysis

TA — не гадание, а структурированный взгляд на цену, объём и тайминг.
Подход top-down: индекс → сектор → бумага → таймфрейм решения.

<HARD-GATE>
Не переходи к фазе 4, пока не сформулирован setup со всеми четырьмя числами:
вход / стоп / цель / инвалидация. R:R ≥ 2 обязательно, иначе setup отклоняется.
</HARD-GATE>

## Multi-timeframe map (правило трёх экранов Эльдера)

- [ ] **Старший (W/M):** определяет глобальный тренд. Если на месяце нисходящий —
      long-only откладывается.
- [ ] **Средний (D):** сигналы входа и выхода.
- [ ] **Младший (H4/H1):** тонкая настройка точки входа.

## Базовый чек-лист

- [ ] **Trend.** Higher highs + higher lows = uptrend. EMA(20)/EMA(50)/EMA(200)
      сверху вниз — конфигурация подтверждения uptrend.
- [ ] **Поддержка / сопротивление.** 2–3 ближайших уровня, видимых на графике.
- [ ] **Объём.** Растущий тренд на растущем объёме. Дивергенция объёма
      (цена выше, объём падает) — предупреждение.
- [ ] **Momentum.** RSI(14), MACD. Перекупленность > 70 / перепроданность < 30 —
      не сигнал к развороту сами по себе, только в контексте уровней.
- [ ] **Волатильность.** ATR(14) — для расчёта стопа (1.5–3 ATR).
- [ ] **Bollinger / Keltner.** Сжатие предсказывает выход импульса.
- [ ] **Свечные паттерны** на ключевых уровнях: pin bar, engulfing,
      evening/morning star.
- [ ] **Графические паттерны:** треугольники, флаги, head & shoulders,
      double top/bottom — с явной целью и инвалидацией.
- [ ] **Дивергенции** RSI/MACD vs цена, особенно на старшем таймфрейме.

## Контекст рынка

- [ ] Тренд бенчмарка (из scope, фаза 0).
- [ ] Тренд сектора.
- [ ] Relative strength vs benchmark — лидер / лагает.
- [ ] Корреляция и β.

## Setup (обязательно с числами)

Без чисел TA бесполезен. Используй шаблон `shared/templates/03-technical.md`.

- **Entry:** диапазон цен + триггер (например, «$148–$152 при касании EMA50 +
  bullish engulfing на дне диапазона»).
- **Stop-loss:** ниже структурного уровня, через ATR. Не «5% от входа».
- **Take-profit 1/2/3:** ближайшее сопротивление / измеренное движение /
  Fibonacci 1.272/1.618. Доли фиксации: например 50% / 30% / 20%.
- **Invalidation:** условие, при котором setup сломан до достижения стопа
  (например, закрытие дня ниже структурного уровня).
- **R:R:** (avg TP − entry) / (entry − stop) ≥ 2.0. Иначе сделку не открываем.

## Анти-curve-fitting

- Паттерны строятся на ≥ 4 касаниях, не на 3.
- Если для подтверждения нужно «вот тут чуть-чуть глаза прищурить» — паттерна нет.
- Backtest заявленных уровней: если уровень тестировался < 10 раз — слабая выборка.
