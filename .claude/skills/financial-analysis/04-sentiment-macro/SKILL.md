# Фаза 4 — Sentiment / macro / regulatory

Внешний слой, который ломает даже самый красивый DCF.

<HARD-GATE>
Не переходи к фазе 5, пока не составлен список триггеров (что должно случиться,
чтобы тезис подтвердился или сломался) с привязкой к датам.
</HARD-GATE>

## Под-секции

### 4.1 Новости и события (окно 30–60 дней)

- [ ] Гайденс изменения.
- [ ] M&A, divestitures.
- [ ] Свежий отчёт.
- [ ] Downgrade / upgrade от sell-side.
- [ ] Earnings calendar: дата ближайшего отчёта. Открыть позицию по DCF за 3 дня
      до отчёта = ставка на сюрприз, это уже другой тип сделки.
- [ ] Конференции, investor days.

### 4.2 Sentiment indicators

- [ ] **Short interest** + days-to-cover. Высокий short → squeeze risk
      или фундаментальная проблема.
- [ ] **Put/Call ratio**, open interest на ключевых страйках.
- [ ] **Analyst consensus**: средний target, разброс (стандартное отклонение),
      % buy/hold/sell.
- [ ] **Insider transactions** (6 месяцев). Крупные продажи топа или совета — флаг.
- [ ] **Institutional ownership** изменения (13F для США).
- [ ] **News / social sentiment** (NLP, если доступен).
      Данные шумные — используй с осторожностью.

### 4.3 Макро (применять выборочно)

- [ ] Чувствительность к ставкам ЦБ.
- [ ] Чувствительность к валютной паре (выручка / затраты).
- [ ] Цикл сырья (для commodity).
- [ ] Инфляция, потребительский спрос (CPI, retail sales).
- [ ] Геополитика, если применимо (санкции, экспортный контроль).

### 4.4 Regulatory & ESG

- [ ] Открытые расследования, антимонополька, налоговые претензии.
- [ ] Санкции / экспортный контроль.
- [ ] Климатические и социальные риски (для chувствительных индустрий).

## Список триггеров (обязательный вывод)

| Триггер | Срок | Direction | Impact (low/med/high) |
| Earnings X | YYYY-MM-DD | +/- | high |
| Решение по ставке | YYYY-MM-DD | - | med |
| ... | ... | ... | ... |

«Direction» = к чему сместится тезис при наступлении.
Это вход для фазы 5 (synthesis) и monitoring в фазе 6.
