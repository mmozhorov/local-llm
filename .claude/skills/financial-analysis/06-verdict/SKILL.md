# Фаза 6 — Verdict & action plan

Финальный документ, который пользователь читает один.

<HARD-GATE>
Артефакт фазы 6 создаётся ТОЛЬКО после прохождения фаз 0–5 и наличия всех
их артефактов на диске. Любая попытка пропустить — нарушение протокола.

Перед сохранением — обязательный полный self-review (см. `shared/self-review.md`).
</HARD-GATE>

## Структура одностраничника

Используй шаблон `shared/templates/06-verdict.md`.

1. **TL;DR (3 строки):** тикер, рекомендация, цель/срок.
2. **Тезис (5–7 строк):** почему именно сейчас, чем компания отличается.
   Опирается на фазы 1–2.
3. **Анти-тезис (3–5 строк):** что говорят скептики (берём из bear case
   фазы 5) и почему агент не согласен. Если согласен — пересмотр тезиса.
4. **Сценарии (таблица):** Bull / Base / Bear, P, target, E(contribution).
   Итог — E(price) и апсайд к текущей цене.
5. **Action plan:**
   - **Size.** Размер позиции в % портфеля. Метод: Kelly fraction × коэффициент
     осторожности (typically × 0.25–0.5), или фиксированный % из scope.
   - **Entry.** Диапазон + тип ордера (limit / market) из фазы 3.
   - **Stop-loss.** Из фазы 3 + правила по фундаменту (например, «закрытие
     ниже $X *или* miss EPS > 15%»).
   - **Take-profit:** TP1 / TP2 / TP3 с долями.
   - **Horizon.** Когда следующий обязательный пересмотр тезиса.
6. **Monitoring** — таблица метрик и событий с порогами:

   | Метрика / событие | Порог | Действие |

   Это live-документ, обновляется при каждом отчёте / триггере.
7. **Disclaimer:** «Не является индивидуальной инвестиционной рекомендацией.»

## Position sizing (короткая шпаргалка)

- **Fractional Kelly:** f = (p·b − q) / b, где p — вероятность выигрыша,
  b — отношение выигрыша к проигрышу, q = 1 − p. На практике используй 0.25–0.5
  полного Kelly (полный — слишком волатилен).
- **Volatility targeting:** размер = (target_vol_portfolio / asset_vol) × cap.
- **Hard cap:** ни одна позиция не > 10–15% портфеля для retail
  (если не контролирующая доля в семейном бизнесе).

## Self-review (обязательно перед финализацией)

Полный прогон по `shared/self-review.md`. Особо:

- Target price в TL;DR == target в сценариях == fair value фазы 2 ± объяснимый сдвиг.
- Горизонт в plan == горизонт в scope.
- Bull / Bear покрывают экстремумы, не «два base case в разных декорациях».
