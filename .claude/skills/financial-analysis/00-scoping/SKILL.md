# Фаза 0 — Scoping

Цель: не начинать анализ, пока не понятны параметры, без которых вывод бессмыслен.

<HARD-GATE>
Не переходи к фазе 1, пока scope не зафиксирован и не подтверждён пользователем (или пока явно не приняты дефолты с подтверждением).
</HARD-GATE>

## Checklist

Спроси по одному параметру, по одному вопросу в сообщении, multiple-choice предпочтительнее.

1. **Горизонт инвестирования** — критично:
   - intraday / swing (дни)
   - 1–6 месяцев
   - 6–24 месяца (базовый)
   - 2–10 лет (buy-and-hold)
2. **Базовая валюта** — USD / EUR / RUB / другая. Определяет валютные риски.
3. **Бенчмарк** — S&P 500 / Nasdaq 100 / MOEX / отраслевой ETF / другой.
4. **Риск-профиль** — допустимая просадка позиции (5% / 15% / 30%+) и
   максимальный размер позиции (% портфеля).
5. **Цель работы** — принятие решения по сделке / due diligence для дискуссии /
   учебный кейс / подготовка к собеседованию.
6. **Известные позиции** — уже в портфеле, шорт, опционы, нет позиции.
   Влияет на anchoring bias анализа.

## Дефолты (если пользователь отказывается уточнять)

Зафиксируй явно и попроси подтверждения одним сообщением:

> «Принимаю дефолты: горизонт = 12 месяцев, валюта = USD, бенчмарк = S&P 500,
> допустимая просадка = 15%, размер позиции ≤ 5% портфеля, нет открытых позиций.
> Подтвердите или скажите, что поменять.»
