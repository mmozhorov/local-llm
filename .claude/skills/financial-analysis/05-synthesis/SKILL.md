# Фаза 5 — Synthesis

Цель: свести фундамент, технику и сентимент в три сценария
и явный risk register.

<HARD-GATE>
Не переходи к фазе 6 (verdict), пока:
1. Все три сценария готовы (bull / base / bear).
2. Σ вероятностей = 100%.
3. У каждого сценария есть leading indicator подтверждения и опровержения.
4. Risk register имеет kill switches.
</HARD-GATE>

## Три сценария

Для каждого сценария:

| Поле | Что |
|---|---|
| **Предпосылки** | 3–5 ключевых допущений |
| **Драйверы** | Что должно произойти, чтобы сценарий реализовался |
| **Целевая цена** | По тому же методу, что в фазе 2 (DCF / multiples) |
| **Вероятность** | Субъективная, но обоснованная (типичная разбивка 25 / 50 / 25) |
| **Что увижу первым** | Leading indicator подтверждения |
| **Что сломает** | Leading indicator опровержения |

Используй шаблон `shared/templates/05-synthesis.md`.

### Базовая оценка

E(price) = Σ P_i × Target_i

Сравни с текущей ценой: апсайд / даунсайд / нейтрально.

## Sensitivity table (обязательно)

Минимум 2 параметра × 3 значения каждый → 9-клеточная таблица:

- Параметры: revenue growth, terminal margin, WACC, exit multiple
  (выбери 2 наиболее чувствительных).
- Видно, где модель «хрупкая».

## Risk register

| Риск | P | Impact | Митигация | Kill switch |
| --- | - | --- | --- | --- |

«Kill switch» — конкретное условие выхода из позиции (цена / новость / метрика).
Не «если плохо станет», а «если FCF Q1 < $X млрд» или «если price < $Y три дня
закрытия подряд».

## Cross-check

- [ ] Технический setup (фаза 3) согласован с base case (тайминг).
- [ ] Триггеры из фазы 4 учтены как leading indicators сценариев.
