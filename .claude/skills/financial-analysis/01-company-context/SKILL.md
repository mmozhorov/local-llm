# Фаза 1 — Company context

Цель: один pager, отвечающий на вопрос «почему эта компания вообще существует и кто её клиент».

<HARD-GATE>
Не переходи к фазе 2 (fundamental), пока не определена бизнес-модель в одном абзаце и peer set из 5–8 компаний. Без peers невозможны мультипликаторы фазы 2.
</HARD-GATE>

## Checklist

- [ ] **Бизнес в одном абзаце.** Что продаёт, кому, как зарабатывает, чем платит за рост.
      Конкретно. Не «техкомпания», а «вертикально интегрированная экосистема премиум
      потребительской электроники + сервисный бизнес».
- [ ] **Сегменты выручки.** Доли + темпы роста + маржа по каждому. Источник: годовой
      отчёт, последний доступный FY.
- [ ] **География.** Доли по регионам, экспортная зависимость, валютные риски.
- [ ] **Цепочка создания стоимости.** Где компания: добыча / переработка / дистрибуция
      / розница / IP / платформа.
- [ ] **Moat.** Один из 5 типов (network effects / switching costs / cost advantage /
      intangibles / efficient scale) с обоснованием. Если ни одного — пометь.
- [ ] **Peer set.** 5–8 компаний, сопоставимая бизнес-модель, география, размер.
      Этот список — вход для фазы 2.
- [ ] **Регуляторное окружение.** Санкции, антимонополька, лицензии, ESG-риски.
- [ ] **Структура собственности.** Контролирующий акционер, free float, инсайдерская доля.
- [ ] **Стадия жизненного цикла.** Growth / mature / cyclical / turnaround.
      Определяет, какие метрики ключевые в фазе 2.

## Источники

Обязательны: годовой отчёт + investor presentation + Wikipedia (для контекста) +
свежий обзор сектора. В Claude Code — обязательный web search для свежести.
В локальном Ollama — пользователь приносит материалы.
