# Anti-patterns и когнитивные искажения

Проверяй каждый артефакт по этому каталогу перед сохранением.

| Паттерн | Симптом | Контрприём |
|---|---|---|
| **Anchoring** | «Год назад акция стоила $200, значит $130 — дёшево» | Сравнивай с fair value (фаза 2), а не с историей цены |
| **Confirmation bias** | Игнор фактов против тезиса | Обязательный bear case с конкретикой (фаза 5) |
| **Recency bias** | Экстраполяция последнего квартала на 10 лет | Минимум 5y, лучше 10y данных в фундаментале |
| **Survivorship** | «Компании сектора растут по 20%» без учёта закрывшихся | Используй индексы / equally-weighted peer median |
| **Narrative fallacy** | Красивая история без чисел | YAGNI к нарративам, не подтверждённым P&L/CF |
| **Curve fitting в TA** | «Идеальный треугольник» на 3 точках | Минимум 4 касания, объём подтверждает |
| **Over-precision** | «Target $147.83» | Возвращай диапазон ($140–$160), центральное значение |
| **Single-method valuation** | Только DCF или только мультипликаторы | Минимум 2 метода, расхождение объясняется |
| **Ignoring base rates** | «У компании отличный шанс выйти в новый рынок» — без статистики, сколько вообще такое получается | Base rate из истории сектора |
| **Vibe investing** | Финальный тезис без артефактов фаз 0–5 | HARD-GATE |
| **Hindsight в backtest** | «На таких уровнях акция всегда отскакивала» — на 3 случаях | Требуй N ≥ 10 или явно помечай как weak evidence |
| **Author bias** | Брать sell-side target как факт | Sell-side — это input, не вывод |
| **Authority bias** | «Баффетт купил → значит хорошо» | Buffett buys ≠ твоя ситуация. Используй как сигнал для DD, не как тезис |
| **Conjunction fallacy** | «Компания вырастет и захватит рынок и удержит маржу» | Произведение вероятностей < минимума |
| **Hot hand fallacy** | «4 квартала подряд beat → продолжит» | Beat-streak имеет короткую полу-жизнь |
