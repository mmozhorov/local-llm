# Self-review checklist

Прогоняй этот чек-лист **перед каждым артефактом** и **перед финальным verdict (фаза 6)**.
Принцип: смотри на текст свежими глазами, как будто его написал другой человек.

## 1. Placeholder scan

- [ ] В тексте нет «TBD», «TODO», «—», пустых таблиц.
- [ ] Все числа имеют конкретное значение, не «X%».
- [ ] Все ссылки на источники проставлены (или помечены `[hypothesis]`).

## 2. Internal consistency

- [ ] Target price в одностраничнике совпадает с DCF (фаза 2) и synthesis (фаза 5).
- [ ] Горизонт совпадает между scope (фаза 0) и тезисом (фаза 6).
- [ ] Уровни TA (фаза 3) совместимы с таймингом тезиса.
- [ ] Сценарии (фаза 5) не противоречат risks (фаза 4).

## 3. Scope check

- [ ] Тезис не выходит за горизонт из scope (если scope = 1 год, нет прогнозов на 10).
- [ ] Размер позиции соответствует риск-профилю из scope.
- [ ] Валюта вывода = валюта scope.

## 4. Ambiguity

- [ ] Каждая метрика имеет единицу: валюту, процент, единицы, период.
- [ ] «Маржа 12%» — gross / operating / net указан.
- [ ] «Рост 20%» — YoY / QoQ / CAGR указан.
- [ ] «P/E 15» — trailing / forward указан.

## 5. Evidence audit

- [ ] Каждое числовое утверждение имеет источник или метку `[hypothesis]`.
- [ ] Свежесть данных в пределах допустимых окон (см. `data-sources.md`).
- [ ] Sell-side targets не выдаются за свои.

## 6. Anti-pattern audit

- [ ] Прогон по `anti-patterns.md`.
- [ ] Особое внимание: anchoring, single-method valuation, vibe investing,
      narrative without numbers.

## 7. Three-scenarios check (только перед фазой 6)

- [ ] Bull / Base / Bear все три присутствуют.
- [ ] Σ вероятностей = 100%.
- [ ] У каждого сценария есть leading indicator подтверждения и опровержения.

## 8. Disclaimer

- [ ] В финальном документе (фаза 6) есть строка:
      «Не является индивидуальной инвестиционной рекомендацией».

## Что делать с найденным

- Незначительное (форматирование, опечатка, единица измерения) → исправь inline и иди дальше.
- Существенное (target не сходится, нет bear case, single-method) → вернись к соответствующей фазе.
- Систематическое (повторяется в нескольких артефактах) → пометь в `06-verdict.md`
  как known limitation; не маскируй.
